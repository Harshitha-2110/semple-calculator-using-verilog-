# semple-calculator-using-verilog-
Simple Calculator Using Verilog

Description

A simple Verilog-based calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division on two input numbers.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Operation selected using a 2-bit control signal
- Verilog testbench for simulation

Operation Table

"op"| Operation
"00"| Addition
"01"| Subtraction
"10"| Multiplication
"11"| Division

Files

- "calculator.v" – Calculator design module
- "calculator_tb.v" – Testbench for simulation

Tools

- Verilog HDL
- Icarus Verilog
- GTKWave (optional)
- ModelSim / Vivado

Simulation

The testbench applies different input values and verifies the output for all four arithmetic operations.

Applications

This project demonstrates basic arithmetic logic implementation using Verilog HDL and can be used as a beginner FPGA/digital-design project.
